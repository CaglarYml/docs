---
title: 'ESXI Üzerinde Ubuntu Kurulumu'
description: 'Brolve.com üzerinden satın aldığınız Nested hizmetinde Vmware ESXI üzerinde Ubuntu Server nasıl kurarsınız?'
---

<Tip>
  Öncelikle eğer henüz bir hizmete sahip değilseniz [Nasıl Satın Alım Yapılır](https://docs.brolve.com/satin-alim) konulu makalemizi inceleyebilirsiniz.&#x20;
</Tip>

<Steps>
  <Step title="Ubuntu ISO İndirme">
    Ubuntu'nun resmi sayfası üzerinden Ubuntu Server 24.04 ISO(kurulum dosyası) imajını indiriyoruz. Bağlantı: [https://ubuntu.com/download/server](https://ubuntu.com/download/server)
  </Step>

  <Step title="ISO Dosyasını Datastore'a Ekleme">
    Tarayıcı üzerinden ESXI panelinize bağlanın, ardından soldaki bardan **Storage** butonuna tıklayın. Sonrasında üst tarafta bulunan **Datastore Browser** butonuna tıklayın. Sol üstte bulunan Upload butonuna tıklayın ve açılan pencereden ISO dosyasını seçin ve sunucuya yükleyin.
  </Step>

  <Step title="Sanal Makine (VM) Oluşturma">
    * ESXI panelinizin anasayfasına ulaşın.&#x20;

    * Üstte bulunan **Create/Register VM** butonuna tıklayınız.

    * **Create a new virtual machine** seçeneğini seçip **Next** tuşuna tıklayın.

    * Name kısmına makinenin adını girin. Guest OS Family kısmını **Linux**, Guest OS Version kısmında **Ubuntu Linux 64-bit** seçeneğini seçin ve **Next** tuşuna tıklayın.

    * Gelen sayfada CPU, RAM, Disk, Driver gibi seçenekleri düzenleyin.

    * **CD/DVD Drive** bölümünde Host Device yerine **Datastore ISO file** seçeneğini seçin ve ardından datastore'a yüklediğimiz ISO imajını seçin, **Select** tuşuna basın, **Next** tuşuna basın.&#x20;

    * Son kontrolleri yaparak **Finish** tuşu üzerinden bitirin.
  </Step>

  <Step title="Ubuntu Kurulum">
    Sanal makineye güç verin ve makinayı önizleyin. Sırasıyla gelen adımları izleyin. Bu süreçte sizden dil, klavye düzeni, ağ ayarı, disk ayarı, kullanıcı ve şifre bilgisi gibi detayları girmenizi isteyecektir.
  </Step>
</Steps>
<Note>
  ESXi üzerinde Ubuntu Server Kurulum hizmetimiz vardır. İlgileniyorsanız bizimle iletişime geçin!
</Note>
