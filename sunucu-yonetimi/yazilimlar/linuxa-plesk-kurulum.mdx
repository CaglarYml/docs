title: "Linux Üzerinde Plesk Kurulum"
description: "Brolve.com üzerinden alınan Linux işletim sistemi kurulu sunucu hizmetine cPanel Web Yönetim Paneli nasıl kurulur?"
---

<Tip>
  Öncelikle eğer henüz bir hizmete sahip değilseniz [Nasıl Satın Alım Yapılır](https://docs.brolve.com/satin-alim) konulu makalemizi inceleyebilirsiniz.&#x20;
</Tip>

<Warning>
  Makale hazırlanırken Plesk'in resmi kurulum makalesi esas alınmıştır.
</Warning>

<Steps>
  <Step title="Gereksinimler">
    **1) Lisans:**
    [plesk.com](https://plesk.com) üzerinden bir adet lisans satın almanız gerekir.  Ardından lisansınızı hizmetinizin ip adresine yönlendirin.

    **2) Sistem Gereksinimleri:**

    | Sürüm:       | RAM (GB)                            | Disk Alanı (GB)                       |
    | ------------ | ----------------------------------- | ------------------------------------- |
    | Ubuntu 20.04 | **Minimum**: 2GB, **Önerilen**: 4GB | **Minimum**: 20GB, **Önerilen**: 40GB |
    | Ubuntu 22.04 |                                     |                                       |
    | AlmaLinux 9  | **Minimum**: 2GB, **Önerilen**: 4GB | **Minimum**: 20GB, **Önerilen**: 40GB |
    | Debian 12    | **Minimum**: 2GB, **Önerilen**: 4GB | **Minimum**: 20GB, **Önerilen**: 40GB |
  </Step>

  <Step title="Plesk Kurulum">
    Otomatik kurulum her şeyi yaptığı için sizin ekstra bir şeye ihtiyacınız yoktur.

    ### Tek Tıkla Kurulum:

    ```bash
    sh <(curl https://autoinstall.plesk.com/one-click-installer || wget -O - https://autoinstall.plesk.com/one-click-installer)
    ```

    ### Tarayıcı Üzerinden Kurulum:

    * Aşağıdaki komut ile kurulumcuyu indirin.

    ```bash
    wget https://autoinstall.plesk.com/plesk-installer
    ```

    * Aşağıdaki komutla çalıştırılabilir iznini verin.

    ```bash
    chmod +x plesk-installer
    ```

    * Aşağıdaki komutla kurulum yardımcısını çalıştırın.

    ```bash
    ./plesk-installer --web-interface
    ```

    * 8447 portuyla web arayüzüne ulaşın. Örnek URI `http://ip-adresi:8447` veya `http://sunucu-adi.com:8447`.

    * Arayüze giriş bilgileriniz: `root` kullanıcı ve cihaz şifrenizdir.

    * "Install or upgrade product" butonuna tıklayınız.

    * Son çıkan **stable** sürümü seçip, "Continue" butonuyla devam edin.

    * Yükleyeceğiniz paketleri seçip, "Continue" butonuyla devam edin.

    * Bir konsol çıktısı göreceksiniz, kurulum bitene kadar bekleyiniz.

    ### Web Kurulum Otomasyonuyla Kurulum:

    * [https://get.plesk.com/?web-installer](https://get.plesk.com/?web-installer) adresi üzerinden otomasyon sayfasına ulaşın.

    * Gerekli IP adresi, port, kullanıcı adı, şifre bilgilerini girin.

    * Son Kullanıcı Lisans Sözleşmesi(EULA)sini onayladıktan sonra "Install" butonuna tıklayınız.

    * Kurulum bitene kadar bekleyiniz. **15 dakika inaktiflik durumunda sayfa kendini kapatacaktır.**
  </Step>

  <Step title="Kurulum Sonrası">
    Kurulum bittikten sonra `http://ip-adresi:8443` veya `http://sunucu-adi.com:8443` URI'leri üzerinden arayüze ulaşın ve Yönetici hesabını kaydolunuz. Sonrasında `admin` kullanıcı adı ve az önce girdiğiniz şifre ile giriş yapabilirsiniz. Lisans aşamasında 30 günlük deneme lisansı başlatabilirsiniz veya 1. aşamada aldığınız lisansın kodunu giriniz.
  </Step>
</Steps>

<Note>
  Sunucu hizmetinize Plesk Web Hosting Yönetim Paneli kurulum hizmetimiz vardır. İlgileniyorsanız bizimle iletişime geçin!
</Note>
