---
title: "Plesk Hizmetinde PHP Eklenti Aktifleştirme"
description: "Brolve.com üzerinden satın aldığınız Plesk tabanlı web hosting hizmetinde nasıl PHP eklentisi aktifleştirirsiniz/deaktifleştirirsiniz?"
---

<Tip>
  Öncelikle eğer henüz bir hizmete sahip değilseniz [Nasıl Satın Alım Yapılır](https://docs.brolve.com/satin-alim) konulu makalemizi inceleyebilirsiniz.&#x20;
</Tip>

<Steps>
  <Step title="Eklentiler" icon="Warn" stepNumber="1">
    Plesk Web Hosting paketlerimiz üzerinde gerekli tüm PHP eklentileri hâlihazırda aktif durumdadır.
  </Step>
</Steps>

<Note>
  PHP sürümünüzü değiştirmek için [**Plesk Hizmetinde PHP Sürüm Değiştirme**](https://docs.brolve.com/web/plesk/php-surum-degistirme) **konulu makalemizi inceleyebilirsiniz.**
</Note>

<Info>
  Eğer yardıma ihtiyaç duyarsanız [Discord](https://discord.gg/brolve) topluluğumuz üzerinden bir destek talebi oluşturarak bizimle iletişime geçin.
</Info>
